[source,python]

def fibonacci(n):
    """Generate Fibonacci sequence up to n terms."""
    if n <= 0:
        return []
    elif n == 1:
        return [0]
    elif n == 2:
        return [0, 1]

    sequence = [0, 1]
    for i in range(2, n):
        sequence.append(sequence[i-1] + sequence[i-2])

    return sequence

# Example usage
fib_sequence = fibonacci(10)
print(f"First 10 Fibonacci numbers: {fib_sequence}")
----

== Bibliography and citations

Asciidoctor supports semantic
https://docs.asciidoctor.org/asciidoc/latest/sections/bibliography/[bibliography]
sections. The `[bibliography]` style is applied to a section containing a list
of entries, and each entry starts with a `[[[id]]]` anchor that can be cited
from anywhere in the book using the standard cross-reference syntax.

This template's bibliography lives in `src/references.adoc`, which is included
as the final chapter of the book.

According to <<ref1>>, advanced documentation techniques are essential for
technical writing. The <<asciidoc>> documentation provides comprehensive
coverage of the language's features.

== Glossary

Asciidoctor also supports semantic
https://docs.asciidoctor.org/asciidoc/latest/sections/glossary/[glossary]
sections. The `[glossary]` style is applied to a description list, and each term
is rendered with its definition indented beneath it.

This template's glossary lives in `src/glossary.adoc`, which is included near
the end of the book, before the bibliography.

== Index terms

Asciidoctor supports
https://docs.asciidoctor.org/asciidoc/latest/sections/user-index/[index terms],
which mark words and phrases for inclusion in a back-of-book index. A visible
term flows into the text at the point it's declared; a concealed term is indexed
without adding any visible text.

((Asciidoctor)) is the toolchain that compiles AsciiDoc source into PDF, EPUB,
and HTML.

This template uses AsciiDoc as its markup language.(((Markup languages,
AsciiDoc)))

The equivalent block macros, indexterm2:[compiler] and indexterm:[Toolchain,
compiler], can be used in place of the parenthetical syntax.

Only the `asciidoctor-pdf` converter compiles these terms into a visible index –
see the *Index* chapter at the end of the PDF edition of this book.

== Appendices

Asciidoctor supports
https://docs.asciidoctor.org/asciidoc/latest/sections/appendix/[appendix]
sections. The `[appendix]` style is applied to a top-level section, which is
then automatically labelled and lettered (Appendix A, Appendix B, and so on),
independently of the numbered chapters that precede it.

This template includes two example appendices, `src/appendix-a/index.adoc` and
`src/appendix-b/index.adoc`, included immediately after the main chapters.

== Abstract

Asciidoctor has two different features named "abstract", and only one of them
works with the `book` doctype that this template uses.

The
https://docs.asciidoctor.org/asciidoc/latest/sections/abstract/[abstract section style]
– applying `[abstract]` directly to a heading – only works on the first section
of an `article` document. It's rejected by the `book` doctype.

The
https://docs.asciidoctor.org/asciidoc/latest/sections/abstract-block/[abstract block style],
by contrast, is just a paragraph or open block styled with `[abstract]`, and it
works in any doctype. This template uses the block style in `src/abstract.adoc`,
an optional front-matter chapter included right after the dedication. Delete the
file, and its `include::` line in `src/index.adoc`, if your book doesn't need
one.

== Epigraph

Unlike dedication, preface, colophon, and the other front-matter chapters
demonstrated in this book, "epigraph" isn't an official Asciidoctor section
style – there's no dedicated formatting behavior for it.

An epigraph is conventionally a short, unattributed-to-the-author quotation set
apart on its own page near the start of a book. This template approximates that
with `src/epigraph.adoc`, which reuses the `[dedication%notitle]` style –
centered, unnumbered, titleless – around a standard `[quote]` block (see the
"Quotes and citations" section, above, for more on that syntax). Replace the
placeholder quote, or delete the file and its `include::` line in
`src/index.adoc` if your book doesn't need one.

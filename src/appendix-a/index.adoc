= Installation guide

This appendix demonstrates the
https://docs.asciidoctor.org/asciidoc/latest/sections/appendix/[`[appendix]`]

== System requirements

* Operating system: Linux, macOS, or Windows
* Memory: 4GB RAM minimum
* Storage: 1GB available space

= Requirements

:link-asciidoctor-vscode-ext: https://marketplace.visualstudio.com/items?itemName=asciidoctor.asciidoctor-vscode
:link-docker-desktop: https://www.docker.com/products/docker-desktop/

The only requirements are {link-docker-desktop}[Docker Desktop] and a good AsciiDoc editor – try VS Code with the {link-asciidoctor-vscode-ext}[AsciiDoctor extension].

On Windows, it is RECOMMENDED to configure Docker to use WSL 2, and then run the build commands from a WSL terminal. Linux emulators like Git Bash may not be sufficient.

Make sure the `run/*` scripts are executable:

----
$ chmod +x run/*
----

The script to start the container will run the container under the current user and group. You should add your user to the `docker` group, which will allow you to run Docker commands without needing to use `sudo`.

----
$ sudo usermod -aG docker [your-username]
----
